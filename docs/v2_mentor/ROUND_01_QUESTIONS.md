## R1-Q01 三块画板是否来自同一套生成流程？

**已知事实**

- 三块画板在同一份 `.fig` 中，但结构差异很大：
  - DOM 版：125 个 Frame，只有 1 个 `stackMode`，166 个 Text，24 张唯一原图。
  - URL 自主截图版：223 个 Frame，220 个 `stackMode`，166 个 Text，1 张全页图重复 44 次。
  - 上传截图版：136 个 Frame，0 个 `stackMode`，160 个 Text，1 张全页图重复 42 次。
- 字体也不同：DOM 版是 Noto Sans SC；URL 自主截图版是 Inter；上传截图版是 Noto Sans SC。

**为什么问**  
这决定了我们该把哪一块当作“结构基线”。如果三块来自不同流程，就不能把它们的差异简单归因于“DOM / 截图输入不同”。

## R1-Q02 URL 自主截图版的 220 个 `stackMode` 是真布局还是结构标记？

**已知事实**

- 220 个 Frame 带 `stackMode`。
- 其中 133 个有不止一个子节点，87 个只有 1 个子节点。
- 44 个子节点带 `stackPositioning=ABSOLUTE`。
- 144 个子节点带 `stackChildAlignSelf=STRETCH`。
- 45 个子节点带 `stackChildPrimaryGrow=1`。
- `stackSpacing` 既有 `null`（151 个），也有 `6`（37 个）、`16`（11 个）、`10`（5 个）等非零值。

## R1-Q04 空白间隔 Frame 是否是推荐模式？

**已知事实**

- DOM 版外层 11 个直接子项中，6 个是内容 Frame，5 个是空白间隔 Frame。
- 间隔分别是：焦点前 20、栏目前 20×3、页脚前 50。

## R1-Q05 原图 vs 全页截图复用，如何取舍？

**已知事实**

- DOM 版：44 个图片填充，24 张唯一原图；原图尺寸包括 142×142（21 个）、106×142（14 个）、190×100（3 个）、280×90（1 个）、590×320（1 个）等。
- URL 自主截图版：44 个图片填充，全部引用同一张 1440×2545 全页图；节点尺寸 1440×2550。
- 上传截图版：42 个图片填充，全部引用同一张 2544×4959 全页图；节点尺寸 2544×4959。
