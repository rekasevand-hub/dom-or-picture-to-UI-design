# R3-EXP-05 · full-page 拼接与 sticky/fixed 同态（受控实验）

> 状态：`completed-for-current-scope`（2026-10-18）。
> 范围：本地受控页面；验证采集方法、接缝与 sticky/fixed 失败模式，不外推到任意真实站点。
> 证据：`output/_r3_experiments/exp05_fullpage_capture.json` 及同目录 PNG。

## 1. 环境与页面

| 项 | 值 |
|---|---|
| 系统 | Windows |
| Playwright | 1.62.0 |
| Chromium | 151.0.7922.34（headless） |
| 视口 | 1200×800 |
| DPR | 1 |
| 语言 | `zh-CN` |
| 网络 | 仅本地 `127.0.0.1` HTTP，无外部资源 |
| 字体 | 系统 Arial / Microsoft YaHei，无远程字体 |
| 动画 | CSS 动画、过渡、光标闪烁全部关闭 |

页面 `output/_r3_experiments/exp05_site/index.html` 包含：

1. `position: sticky` 顶栏，高 64。
2. `height: 100vh` 的 hero，内含 `10vh` 探针。
3. 6 个 600 高的内容块，每块带一个懒加载 240×120 图片。
4. 第 3 块内另有 `top: 64px` 的 sticky 子头。
5. `position: fixed` 左侧 24×`100vh` 条纹和右下 120×40 徽标。
6. 懒加载哨兵：滚入视口后插入 400 高区块。
7. `@media (min-height: 2000px)` 分支，用于观察扩展视口是否改变布局。

## 2. 三种参考

| 模式 | 采集方式 | 采集时 `innerHeight` | 输出 | sticky/fixed 策略 | M0/M1 |
|---|---|---|---|---|---|
| 滚动拼接 | 8 张原视口截图，步长 640，重叠 160 | 800 | 1200×4904 | 每段重复 | 8/8 稳定 |
| 文档捕获 | `page.screenshot(full_page=True)` | 800 | 1200×4904 | 仅文档顶部一次 | 稳定 |
| 扩展视口 | 视口高度改为 4904 后截图 | 4904 | 1200×4904 | 仅视口顶部一次 | 稳定 |

三种模式都记录为 `composite` 或显式状态；没有把任何一种写成“浏览器同时显示了整张长图”。

## 4. 懒加载与状态变化

初始 `docHeight=4504`。滚动过程中：

| 步骤 | scrollY | docH | 懒加载区块数 | 已加载图片数 |
|---|---:|---:|---:|---:|
| fresh-00 | 0 | 4504 | 0 | 1 |
| fresh-01 | 640 | 4504 | 0 | 2 |
| fresh-02 | 1280 | 4504 | 0 | 3 |
| fresh-03 | 1920 | 4504 | 0 | 4 |
| fresh-04 | 2560 | 4504 | 0 | 5 |
| fresh-05 | 3200 | 4504 | 0 | 6 |
| fresh-06 | 3704 | 4904 | 1 | 6 |
| fresh-07 | 4104 | 4904 | 1 | 6 |

事件时间（`performance.now()`）：img-1 在 121ms 开始加载，img-6 在 1137ms 完成；懒加载区块在 1282ms 插入，`docHeight` 从 4504 变为 4904。

因此，插入前的截图只能标 `partial`；只有插入完成并稳定后的 4904 高状态才进入本次整页比较。

## 5. 接缝与像素比较

原始拼接图与文档捕获图同为 1200×4904。未屏蔽任何区域时：

| 指标 | 值 |
|---|---:|
| 平均绝对差 | 21.4613 |
| P99 | 208.3333 |
| 最大差 | 208 |

按无效区域屏蔽后，有效像素占 86.7961%；有效像素的平均绝对差、P99、最大值全部为 0。

| 640 | 189.5989 | 0.0 | 6.0576 | 0.0 | 0.0 |
| 1280 | 203.6096 | 0.0 | 2.2959 | 0.0 | 0.0 |
| 1920 | 192.8506 | 0.0 | 2.2540 | 0.0 | 0.0 |
| 2560 | 203.6096 | 0.0 | 39.1270 | 0.0 | 0.0 |
| 3200 | 192.8506 | 0.0 | 2.3044 | 0.0 | 0.0 |
| 3840 | 194.5586 | 0.0 | 2.2311 | 0.0 | 0.0 |
| 4104 | 190.8839 | 0.0 | 2.2311 | 0.0 | 0.0 |

顶栏带被完整屏蔽，所以“屏蔽后”为空；下方内容的原始差来自左侧 fixed 条纹和 sticky 子头，屏蔽后均为 0。

无效区域共 25 个：sticky 顶栏 7 个、fixed 条纹 8 个、fixed 徽标 8 个、sticky 子头 2 个。按面积计（重叠前）：顶栏 9.135%、条纹 2.610%、徽标 0.653%、子头 1.631%，合计 14.029%；重叠后实际无效像素为 13.2039%。

结论：本次静态页中，滚动拼接与保持原视口的文档捕获在有效区域内几何一致；差异集中在 sticky/fixed 的重复策略，而不是内容本身。

## 6. 扩展视口不等价

把视口高度改为 4904 后：

| 信号 | 原视口 | 扩展视口 |
|---|---:|---:|
| `innerHeight` | 800 | 4904 |
| hero 高度 | 800 | 4904 |
| `10vh` 探针高度 | 80 | 490.39 |
| `(min-height: 2000px)` | false | true |
| `docHeight` | 4904 | 9008 |
| 截图高度 | 4904 | 4904 |
| 是否覆盖完整文档 | 是 | 否（54.44%） |

扩展视口截图与原视口文档捕获在前 4904 像素上的平均绝对差为 25.8598，P99 为 170.3333，最大值为 225。差异不是噪声，而是 `100vh`、视口单位和媒体条件被改变。

## 7. 结论

1. 保持原视口的 `full_page=True` 采集在本环境没有改变 `innerHeight`（M0/M1 均为 800），是三者中最接近整页参考的采集方式；但它仍是 capture-beyond-viewport，不是浏览器同时显示整页。
2. 原视口滚动拼接可以重建与文档捕获一致的内容几何，但必须显式屏蔽并记录 sticky 顶栏、sticky 子头、fixed 条纹和 fixed 徽标；原始拼接图不能直接当作整页参考。
3. 扩展视口会改变 `100vh`、`vh` 探针和媒体查询，并让 `docHeight` 从 4904 增至 9008；本次截图只覆盖新文档的 54.44%，不能作为整页参考。
4. 懒加载会把 `docHeight` 从 4504 推到 4904；未等待插入完成的截图必须标 `partial`。
5. 拼接参考的全局标签必须是 `composite`；固定头策略必须显式记录为“每段重复 / 仅顶部一次 / 隐去”之一。
6. 本实验只证明受控静态页上的方法与失败模式；真实站点的字体、轮播、广告、遮挡和协作状态需要各自证据。
