## 3. 稳定性

用 5 种遍历顺序独立重跑聚类：

- Figma 子项顺序；
- 视觉行优先正序；
- 视觉行优先逆序；
- `x` 降序、`y` 降序；
- 节点 ID 字典序。

5 种顺序得到相同的行/列成员集合。容差取 0.5、1、2 px 时也得到相同分组。

因此，对当前 21 个槽位：

- 行、列分组稳定；
- 槽位尺寸一致；
- 坐标严格落在推导网格上；
- 没有尺寸或位置离群项。
