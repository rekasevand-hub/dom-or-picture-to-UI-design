## R5-Q01 冲突字段的默认交付策略

## R5-Q02 真实 Figma 部分写入失败的事务、回滚与重试

**已知事实**

- Smoke C 在真实 Figma 中重放 `R4-EXP-09` 实际发出的 9 条命令（1 个画板 + 8 个写入），16/16 检查通过；它只覆盖单文档、单次运行，没有注入失败。
- 当前 bridge 逐条创建节点；Smoke C 通过命令返回 ID、`get_node_tree` 与 `export_frame` 验证结果，但没有使用事务、undo 或回滚。
- `R4-EXP-09` 已在执行前校验 action 白名单、必填参数和资产 payload 哈希；非法输入失败关闭，不退回静默默认值。
- 真实失败可能发生在命令前、命令执行中或命令已执行但响应丢失之后；三者不能共用同一处理方式。

**为什么问**

真实 Figma 写入不可能保证 100% 成功。缺少原子单位和失败分类时，一次字体缺失、图片上传失败或超时就可能留下半成品、重复节点，或让用户误以为写入成功。必须先定义“失败后系统欠用户什么”。

2. 对“命令已发出但响应超时”的不确定结果，重试前是否必须先 `get_node_tree` 回读确认？是否要求幂等键或稳定节点名？
3. 重试应创建新节点还是更新已有节点？如果节点名重复，如何避免重复图层和错误覆盖？

6. 回滚应使用 Figma undo、删除本次创建的节点，还是写入独立的隔离页面/Frame？如何避免删除用户已有内容？

## R5-Q03 DOM 与截图的权威边界

**已知事实**

- `R4-EXP-01` 的默认分工是：DOM 负责 `text / font / color / role / editability / asset_source`；截图负责 `visible_state / occlusion / z_order / rendered_effect`；状态门先于字段比较，bbox 使用绝对容差 `2.0 px`。
- `R4-EXP-04` 的 103 条来源决策中，OCR 只提升 `text-content`；`editability / role / asset_source` 永不从截图候选升级。
- `R4-EXP-02` 只有双引擎 exact、最小置信度 ≥ `0.85`、跨引擎 bbox IoU ≥ `0.50` 时才允许提升文本；13 个用例中只有 2 个晋升。
- `R4-EXP-09` 的写入命令按截图 z-order 升序，而不是 DOM 顺序。
- `R3-EXP-13` 已覆盖 Chromium + WebKit 的文本度量；Firefox 因 `spawn UNKNOWN` 未覆盖。

**为什么问**

真实页面里经常出现“DOM 有但屏幕没有”“屏幕有但 DOM 没有”“DOM 文本与渲染文本不同”的情况，例如伪元素、canvas、iframe、shadow DOM、图标字体、CSS `content`、水合前后的旧文本。简单的“DOM 永远负责文本和颜色”会在这些场景下给出错误交付。

**请导师回答**

1. DOM 文本与截图渲染文本不一致时，`faithful` 模式下谁权威？请分别说明伪元素、CSS `content`、canvas、iframe、shadow DOM 和水合/缓存旧 DOM。
2. DOM 中存在但视觉上被隐藏、裁切或完全遮挡的文本，应写为隐藏节点、省略，还是延迟？当前 bridge 无 `visible` 时，哪一种最诚实？
3. CSS `background-image`、渐变、滤镜、混合模式和伪元素装饰，分别算资产、fill，还是 `rendered_effect`？截图颜色因 opacity/blend/filter 不同而偏离 DOM 时，交付哪个？
4. 只存在于截图中的可见文本（文字图片、canvas 文本、图标字体）应视为 OCR 文本、栅格资产，还是参考图层？判定门槛是什么？
5. 跨域 iframe、关闭的 shadow root 或不可访问的 DOM 中，截图是否接管全部字段，还是只接管视觉字段？来源切换如何在 IR 和 manifest 中标记？
6. DOM 兄弟顺序与截图叠放顺序冲突时，谁决定 Figma 子节点顺序？哪些情况必须人工复核？
7. 如何检测 DOM 过期、水合不一致或缓存页面？发现后应输出 `external-conflict`、`unknown`，还是直接降级为截图轨？
8. 融合阶段是否允许把 DOM 结构与截图分组合并？如果允许，需要什么显式授权、逐字段 provenance 和回退条件？
9. `external-conflict`、`unknown`、`unsupported` 三者的边界是什么？请给出最小证据要求。
10. 从截图-only 文本晋升为可编辑文本，除 `R4-EXP-02` 的双引擎门槛外，是否还需要 DOM 交叉证据或人工确认？

**请导师回答**

1. 四个维度中哪些是“可交付”的硬门禁，哪些只影响草稿/参考状态？请分别说明 `pass / partial / fail / unknown`。
2. 区域状态如何汇总为页面状态，且不使用总分：取最差维度、任一阻断、覆盖率加权，还是分层规则？请给默认算法。
